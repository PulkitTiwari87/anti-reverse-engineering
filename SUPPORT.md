# Support

- **Usage questions:** read [docs/getting-started.md](docs/getting-started.md) and
  [docs/faq.md](docs/faq.md) first, then open an issue using the question or bug template.
- **Bugs and feature requests:** open an issue with the provided templates. Include your
  agent and version, the policy profile used (with private details removed), and the
  expected versus actual decision.
- **Security issues:** do not use public issues; see [SECURITY.md](SECURITY.md).
- **Legal questions:** this project gives no legal advice. Consult a qualified professional.

Support is best-effort by volunteers.
